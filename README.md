# IB Extended Essay 2027 — Field Guide

A static learning website for the IB Extended Essay, first assessment 2027. Images, poster frames and videos are included under `public/assets`; the site requires no runtime environment variables.

## Local development

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

Vercel is configured to run `npm ci`, build with `npm run build`, and serve the `dist` directory.
